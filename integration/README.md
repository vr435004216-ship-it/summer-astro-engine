# AstroEngine integration staging

This branch stages integration of the separately developed AstroEngine Python package with the existing `summer_astro` Render API.

The attached local artifact `AstroEngine_context_integrated.zip` is NOT yet committed here. Do not treat this branch as the updated engine or deploy it to Render.

Existing Render service: https://summer-astro-engine.onrender.com
Vercel preview project: astro-engine-preview

Integration requires source transfer, API adapter, dependency verification, tests, and a preview deployment before changing the live service.

No blind friend benchmark has been run.
